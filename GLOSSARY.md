# Календарь звонков

Сервис записи на звонок: один владелец публикует доступное время, а гость выбирает свободный слот.

## Language

**Владелец**:
Единственный человек, чьё время публикуется в календаре.
_Avoid_: Хост, владелец календаря, пользователь, админ

**Гость**:
Человек без учётной записи, который выбирает слот и записывается на звонок.
_Avoid_: Посетитель, клиент, пользователь

**Тип встречи**:
Шаблон звонка с названием, описанием и длительностью, из которого гость выбирает.
_Avoid_: Тип звонка, событие, тип события, услуга

**Слот**:
Отрезок времени, в который может начаться встреча; его длина равна длительности выбранного типа встречи.
_Avoid_: Окно, время, таймслот

**Запись**:
Закреплённый за гостем слот вместе с выбранным типом встречи.
_Avoid_: Бронь, бронирование, резервация, встреча

**Предстоящая запись**:
Запись, время окончания которой ещё не наступило; включает уже идущий звонок.
_Avoid_: Будущая запись (когда речь также об идущем звонке)

**Подтверждение записи**:
Представление сведений об успешно созданной записи для гостя.
_Avoid_: Подтверждение email, подтверждение личности

**Окно записи**:
Период в 14 календарных дней, внутри которого гость может выбрать слот; окно сдвигается с течением времени.
_Avoid_: Горизонт, период доступности, календарь
