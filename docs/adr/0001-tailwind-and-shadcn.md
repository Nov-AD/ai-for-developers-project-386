# Tailwind CSS и shadcn/ui как база стилей веба

README с первого дня обещал Tailwind CSS и shadcn/ui, но `apps/web` оставался на ручном CSS из каркаса Vite. С главной страницей появляется первая настоящая вёрстка, поэтому мы переводим веб на Tailwind CSS 4 (плагин `@tailwindcss/vite`, тема через CSS-переменные) и компоненты shadcn/ui, скопированные в репозиторий. Ручной CSS отвергнут: он уже расходился с README, а каждая следующая страница — запись, календарь слотов — увеличивала бы цену перехода.

## Consequences

- В `apps/web` появляются `components.json`, alias `@/*` и `src/components/ui/*`. Файлы, сгенерированные shadcn, не переписываем без причины: обновление компонента должно оставаться дешёвым.
- Компоненты и их экспорты добавляем по мере надобности — лишнее ловит knip.
- Тёмная тема не заводится, пока её не попросят: в теме только значения `:root`.
