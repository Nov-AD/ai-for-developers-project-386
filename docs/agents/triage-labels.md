# Triage Labels

Скиллы говорят о пяти канонических ролях триажа. Этот файл сопоставляет роли со строками лейблов, которые реально используются в трекере этого репозитория.

| Роль в mattpocock/skills | Лейбл в нашем трекере | Значение                                       |
| ------------------------ | --------------------- | ---------------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить задачу               |
| `needs-info`             | `needs-info`          | Ждём дополнительную информацию от автора       |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описана, готова для AFK-агента       |
| `ready-for-human`        | `ready-for-human`     | Требует реализации человеком                   |
| `wontfix`                | `wontfix`             | Не будет сделано                               |

Когда скилл упоминает роль (например, «поставь AFK-ready triage label»), используй соответствующую строку из таблицы.

Колонку «Лейбл в нашем трекере» правь под ту лексику, которую реально используешь.
